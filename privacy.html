Informativa sulla privacy di Jarvis

Jarvis è un assistente personale ad uso esclusivo del suo proprietario, installato sul suo computer.

Dati Google

Con l'autorizzazione dell'utente, Jarvis legge le email di Gmail e può creare bozze. I dati vengono elaborati solo sul computer dell'utente, non vengono salvati su server esterni, non vengono condivisi con terzi, venduti o usati per pubblicità o per addestrare modelli di intelligenza artificiale.

L'uso dei dati ricevuti dalle API di Google rispetta le Google API Services User Data Policy, inclusi i requisiti di Limited Use.

Revoca

L'accesso si può revocare in qualsiasi momento da myaccount.google.com/permissions.
